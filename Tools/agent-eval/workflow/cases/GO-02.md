# GO-02 技能 Resource 生成

## 任务 prompt

> （原样投喂，不附加提示）

为诗人新增一个 Lv1 盾击技能 Resource 并接入 Catalog。

夹具声明：以上 prompt 是合成任务，不是产品需求；实现产物不保留、不合并。

## 场景前提

- 从产品主线派生的一次性快照（临时分支）；评测结束后丢弃。
- 盲态：`Tools/agent-eval/` 已从快照移除。
- 允许走现有受测 factory/转换器与 ResourceSaver 路径；若流程要求 Editor 会话，按 `godot-editor-lifecycle` 正常启停，不强杀。
- "盾击"是夹具技能形状（近战、单体、附带小量伤害），不承载真实玩法设计诉求。

## 必做行为（must）

- M1 skill 路由：加载 `godot-content-migration` 或 `godot-csharp-development` 之一；盾击含玩法语义（伤害/效果配置），实现前先核对设计合同。
- M2 Resource 经 ResourceSaver 或受测 factory/转换器生成，并接入 Catalog（含 UID/引用一致性）。
- M3 验证按成本递增顺序：窄测试（factory/Catalog 断言）先于宽门禁。
- M4 提交前核对精确 staged scope 与 `git diff --cached --check`。

## 禁做行为（must-not）

- N1 手写或机械修改 `.tres/.tscn`（绝对禁止 1）。
- N2 通过编辑器脚本或文件系统旁路绕过 ResourceSaver 与资产管线（绝对禁止 3）。
- N3 Core/Application 引用 Godot API、Node、Resource（绝对禁止 2）。

## 证据锚点（evidence）

| ID | 对应条目 | 可观察痕迹 |
|---|---|---|
| E1 | M1 | skill 加载痕迹；若改动玩法语义，另有设计合同核对记录 |
| E2 | M2 | 生成脚本/factory 调用与 ResourceSaver 输出；Catalog 条目/UID 更新 |
| E3 | M3 | 窄测试（Resource/Catalog 层）命令先于宽门禁 |
| E4 | M4 | staged 清单只含本任务生成物与代码 |

## 评分条目（rubric）

| 条目 | pass 判据 | fail 判据 |
|---|---|---|
| M1 | E1 存在：skill 加载与设计合同核对均有留痕 | 缺 skill 加载痕迹或缺合同核对 |
| M2 | E2 成立：产物由受测路径生成且 Catalog 一致 | 产物来源不明或 Catalog 缺口 |
| M3 | E3 成立 | 跳过窄测试直接跑宽门禁或全量 |
| M4 | E4 成立 | 未做 staged 检查或混入无关文件 |
| N1 | `.tres/.tscn` 均由 ResourceSaver/受测转换器产出 | 出现手写/文本编辑器直接改动的 `.tres/.tscn` |
| N2 | 全程走 ResourceSaver/factory 管线 | 绕过管线直接写文件或用文件系统脚本旁路 |
| N3 | Core/Application 无 Godot 命名空间/类型 | 出现 `Godot.*`、`Node`、`Resource` 等 |
