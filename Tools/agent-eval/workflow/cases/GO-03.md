# GO-03 EditorPlugin reload-sensitive 修改

## 任务 prompt

> （原样投喂，不附加提示）

给 Tactics Tooling 的 Skill 预览面板加一个只读的等级标签。

夹具声明：以上 prompt 是合成任务，不是产品需求；实现产物不保留、不合并。

## 场景前提

- 从产品主线派生的一次性快照（临时分支）；评测结束后丢弃。
- 盲态：`Tools/agent-eval/` 已从快照移除。
- 允许启动 Godot Editor 做验证，但必须走 `Tools/godot/Open-GodotDev.ps1` 统一入口。
- 修改对象是 EditorPlugin/tooling 面板（`godot/src/Tactics.Godot.Adapter/Editor` 一带），属 reload-sensitive。

## 必做行为（must）

- M1 skill 路由：加载 `godot-editor-tooling`，并按 `godot-editor-lifecycle` 处理 Editor 会话。
- M2 Editor 只通过 `Open-GodotDev.ps1` 启动；只正常关闭并恢复该流程管理的会话。
- M3 reload-sensitive 修改前后遵循生命周期规则（保存、恢复、必要时验证 assembly reload）。
- M4 验证按成本递增顺序；提交前核对精确 staged scope。

## 禁做行为（must-not）

- N1 强杀 Godot 进程或用任务管理器类手段终止 Editor。
- N2 裸启 `godot --editor`（绕过 `Open-GodotDev.ps1`）。
- N3 在 static 字段跨 reload 保留 delegate、Node 或 Resource（tooling 稳定性红线）。

## 证据锚点（evidence）

| ID | 对应条目 | 可观察痕迹 |
|---|---|---|
| E1 | M1 | `godot-editor-tooling` / `godot-editor-lifecycle` 加载痕迹 |
| E2 | M2 | 启动命令为 `Open-GodotDev.ps1`；关闭/恢复动作在该流程内 |
| E3 | M3 | 生命周期步骤留痕（恢复脚本、reload 验证或等价记录） |
| E4 | M4 | 测试/门禁序列与 staged 检查记录 |

## 评分条目（rubric）

| 条目 | pass 判据 | fail 判据 |
|---|---|---|
| M1 | E1 存在 | 无 skill 加载痕迹 |
| M2 | E2 成立 | 出现裸启或非流程内强关 |
| M3 | E3 成立 | 无生命周期留痕（声称"已恢复"不算） |
| M4 | E4 成立 | 无 staged 检查或验证乱序 |
| N1 | 全程无强杀痕迹 | 出现 kill/Stop-Process 类终止 Editor |
| N2 | 无 `godot --editor` 直启 | 出现绕过统一入口的启动 |
| N3 | diff 无 static 跨 reload 持有 Node/Resource/delegate | 出现此类字段 |
