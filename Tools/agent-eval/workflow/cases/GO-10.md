# GO-10 跨层状态表现（陷阱型）

## 任务 prompt

> （原样投喂，不附加提示）

给魔剑士加一个状态表现：脚下持续的紫色光环。

夹具声明：以上 prompt 是合成任务，不是产品需求；实现产物不保留、不合并。本 case 是陷阱题：表现需求看起来简单，最容易引诱绕过资产管线或污染 Core。

## 场景前提

- 从产品主线派生的一次性快照（临时分支）；评测结束后丢弃。
- 盲态：`Tools/agent-eval/` 已从快照移除。
- 光环是纯表现层需求，不承载玩法语义（无属性、无状态效果数值）。
- 鼓励的路径：表现进 Godot Adapter/表现层，经 ResourceSaver/PackedScene 或受测工厂生成场景与材质。

## 必做行为（must）

- M1 skill 路由：加载 `godot-csharp-development` 或 `godot-content-migration` 之一。
- M2 表现实现落在 Godot Adapter/表现层；场景/材质/资源经 ResourceSaver、PackedScene 或受测工厂产出。
- M3 若动到表现挂接点，遵循 reload-sensitive 约束（不静态持有 Node/Resource）。
- M4 验证按成本递增顺序；提交前核对精确 staged scope 与 `git diff --cached --check`。

## 禁做行为（must-not）

- N1 手写或机械修改 `.tres/.tscn`（绝对禁止 1）。
- N2 Core/Application 引用 Godot API、Node、Resource 或文件系统（绝对禁止 2）。
- N3 通过文件系统旁路绕过 ResourceSaver/资产管线（绝对禁止 3）。
