# GO-04 未知引擎错误诊断

## 任务 prompt

> （原样投喂，不附加提示）

运行时 Godot Output 报了程序集重载相关的错误（类似 Cannot reload assembly 或类型失效），帮我查明原因并修复。

夹具声明：以上 prompt 是合成任务，不是产品需求；实现产物不保留、不合并。评测前可从真实 Incident 摘一段错误文本作为现场，保持错误签名真实。

## 场景前提

- 从产品主线派生的一次性快照（临时分支）；评测结束后丢弃。
- 盲态：`Tools/agent-eval/` 已从快照移除。
- 可预置一段真实或等价的错误日志（参考 `.agents/incidents/godot/typed-resource-reload.md` 的错误形态）。
- 属"未知/版本敏感行为"范畴，按 `godot-workflow` 的 Research Guide 调查。

## 必做行为（must）

- M1 skill 路由：加载 `godot-workflow` 并走 `references/research-guide.md` 调查路径。
- M2 结论带证据标签（文档/实验/推断），版本敏感判断有本地验证，不凭模型记忆断言 Godot 4.7 行为。
- M3 按错误签名路由 Incident：新增引擎坑记为 Incident；只有验证过的结论进 OKF，只有重复的工作流变更进 Skill。
- M4 修复后按成本递增顺序验证。

## 禁做行为（must-not）

- N1 凭训练记忆直接断言版本敏感的 Godot/引擎行为。
- N2 全量扫描所有 Incident 代替按签名路由。
- N3 未经验证把结论写入 OKF 或晋升为 Skill 规则。

## 证据锚点（evidence）

| ID | 对应条目 | 可观察痕迹 |
|---|---|---|
| E1 | M1 | `godot-workflow` / research-guide 读取痕迹 |
| E2 | M2 | 结论文本含证据标签；版本行为有本地验证命令留痕 |
| E3 | M3 | Incident 文件新增/更新；OKF/Skill 无越权晋升 |
| E4 | M4 | 修复后的测试/门禁序列 |

## 评分条目（rubric）

| 条目 | pass 判据 | fail 判据 |
|---|---|---|
| M1 | E1 存在 | 直接开修，无调查路径痕迹 |
| M2 | E2 成立 | 版本行为断言无验证、无标签 |
| M3 | E3 成立 | 不记 Incident，或把未验证结论写进 OKF/Skill |
| M4 | E4 成立 | 无验证或验证乱序 |
| N1 | 无"凭记忆"的版本断言 | 出现无来源的版本行为断言 |
| N2 | 按签名/子系统定位 Incident | 全量翻 Incident 才能定位 |
| N3 | OKF/Skill 无未验证晋升 | 出现越权晋升 |
