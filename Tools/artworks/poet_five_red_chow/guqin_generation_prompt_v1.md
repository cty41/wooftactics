# 中国古琴｜独立道具候选 v1

生成一张 Pure Run 小体量等距游戏的独立中国古琴道具身份图。这里的 `consumable` 仅是美术管线的通用小道具风格分类，不表示任何运行时消耗品、装备槽或玩法规则。

## 身份

- 七弦古琴，狭长木质琴体，首部较宽、尾部略收。
- 深栗黑漆木色，少量暖棕边缘与克制金色徽位。
- 七根琴弦必须读作一组整齐平行细线，但在 128px 预览中不能形成密集噪点。
- 琴面有轻微弧度；保留简化的岳山、龙龈和少量琴足结构。
- 不生成古筝的高支架、雁柱或大量可移动琴码。

## Pure Run 风格

- 粗而受控的深棕轮廓、平涂、有限色阶、清楚轮廓。
- 木材只使用少量明确明度块，不做写实木纹、漆面反射或复杂裂纹。
- 128px 预览仍能立即识别为狭长七弦古琴。

## 构图

- 单独一床完整古琴，采用三分之四俯视的对角展示：琴首在画面左下，琴尾在画面右上。
- 物体居中、完整不裁切；可见垂直高度约 120px。
- 纯均匀 #00ff00 绿幕，无人物、手、桌、坐垫、剑、酒器、文字、印章、阴影、场景或 UI。
