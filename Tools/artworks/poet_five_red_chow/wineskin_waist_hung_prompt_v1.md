# 五红土松诗人｜腰挂朝向皮革酒囊单图 v1

制作单独一张专用于 down-right 等距角色腰侧的皮革酒囊组件。保持已批准皮革酒囊的暖棕平涂、扁鼓水滴形、深棕缝边、短壶嘴与克制菱形压纹身份，但必须按真实三维腰挂姿态重新投影，而不是缩放粘贴原库存视角。

- 固定摄像机与已批准诗人 Idle DR 相同：从上方观察角色右前侧。
- 酒囊的系耳/壶嘴位于画面左上并朝角色腰部内收；装酒的囊腹受重力悬垂到画面右下，更靠近镜头。
- 囊体采用侧面三分之四视角：可见轮廓应比库存正视图更窄，一侧缝边更强，另一侧被透视压缩；菱形压纹只部分可见。
- 顶部必须形成可被角色身体遮挡的平直/内收接触边，不能像漂浮在角色旁边。
- 不绘制角色、手、腰带、长肩带、葫芦、古琴、剑、桌面、地面或阴影。
- Pure Run 粗轮廓、2–3 个硬边平涂色块；无柔光、渐变、纹理噪点和拟真材质。
- 单一完整物体居中，纯均匀 #00ff00 绿幕；正式校准目标可见高度约 54px。
