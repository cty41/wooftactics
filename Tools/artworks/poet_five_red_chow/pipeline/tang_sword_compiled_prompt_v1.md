## Base prompt
# 唐代诗人佩剑｜独立装备候选 v1

生成一把中国唐代风格的单手直剑，作为 Pure Run 小体量等距游戏的独立装备身份图。

## 历史与身份

- 双刃直身剑，剑身挺直、比例修长但适合单手佩用。
- 小型横向护手，不使用巨大奇幻十字格。
- 深棕缠柄，简洁圆形或微椭圆首。
- 黑褐漆木剑鞘与克制的铜金色鞘具；剑身完整出鞘展示，不与剑鞘并列。
- 装饰只保留少量唐代几何云纹感，不写文字、不加龙形浮雕。

## Pure Run 风格

- 与绑定的猎人角色和死灵匕首锚点保持同一粗轮廓、平涂、有限色阶。
- 轮廓在 128px 预览中清楚；银灰剑身只用两到三个明确明度区。
- 避免写实金属反射、镜面高光、复杂渐变和 AI 珠宝化细节。

## 构图

- 单独一把完整剑，采用批准的装备对角线展示方向：剑尖朝画面右上，剑柄朝画面左下。
- 物体居中，完整不裁切；可见垂直高度约 160px。
- 纯均匀 #00ff00 绿幕，无阴影、地面、角色、手、酒器、古琴、文字、边框或 UI。
