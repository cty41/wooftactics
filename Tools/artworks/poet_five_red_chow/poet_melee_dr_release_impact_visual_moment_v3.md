# 诗人 Melee DR：Release→Impact Visual Moment v3

状态：production experiment；只授权一张候选，不代表运行时接入、人工批准或晋升。

## 玩家问题

玩家应在战场尺寸下一眼读出：诗人已经拔出环首唐刀，身体向右下目标格完成承诺式下劈；这一刻不是待机、举刀前摇或带持续特效的施法。

## 时间合同

- **进入：** windup 结束、lunge/release 开始时切入。
- **保持：** 覆盖 lunge 和 impact hold。
- **退出：** recover 开始时清除并恢复方向 Idle。
- **当前依赖：** 现行 `GodotBattlePresentationPlayer` 在 windup 前即切入 Melee Texture，与本合同不符。本轮不改运行时代码；候选只能获得离线与静态 Runtime Context 证据，不能声称最终运行时通过。

## 信息所有权

- **Sprite：** 诗人身份、DR 朝向、身体承诺、无臂四爪拓扑、唐刀形制、握持与空鞘状态。
- **Tween：** lunge 位移与 recover。
- **VFX：** 命中位置、伤害性质和短暂冲击；Sprite 本身不带拖尾、光效或命中特效。
- **音效：** 拔刀/劈砍/命中节奏，不由 Sprite 表达。

## 关键姿态

- 角色世界朝向保持 DR；固定等距摄像机下，攻击推进到画面右下。
- 身体不再直立展示武器：核心整体向右前压，重心越过两只后爪中点并靠近右下支撑爪。
- 右下支撑后爪承担刹停，左后驱动爪落后并形成宽而稳定的地面三角；脚底仍守 `y=236` 离线基线。
- 主体从左下驱动爪经重心到右上头肩形成前倾力线；身体中段压缩，头肩与握点向攻击方向伸展。
- 尾巴/后侧轮廓向左上反向张开，平衡右下刀轴，但不得变成额外肢体或大面积抢读。
- 两只前爪均为直接贴合主体的小圆爪：近爪在主体右缘以宽接触面压住刀柄，远爪在握点内侧辅助；不得生成手臂、肘、细连接或人手。
- 刀柄在主体右前缘；直身单刃唐刀以陡斜轴落向画面右下，刀尖完整留在画布内。
- 空鞘保持在侧后方并大部分被主体遮挡，只保留足以读出“已出鞘”的关系；不得出现第二把刀。

## 身份边界

身份只来自正式装备版 Idle DR：肉桂红五红土松、狮形宽头、短宽口鼻、小直立三角耳、紧凑毛茸胶囊体、粗卷尾、两只小暗眼、四只直接贴身圆爪。诗人气质通过克制自信的神态表达，不新增帽、衣服、葫芦、酒囊、古琴、首饰或法术效果。
