# 单帧动作姿态生产与 Review

## 参考图职责

- **角色方向母图**：唯一身份与体量锚点。DR 使用对应角色的已批准 `down-right`，UL 使用已批准 `up-left`。它锁定核心主体、脸部/后脑解剖、耳型、脚位、配色、线宽和装备清单。
- **已批准 DR 动作图**：生成 UL 时只锁定冻结动作时刻、装备状态和动作轴，不迁移正面解剖。UL 必须从正式 UL 母图原生重绘，不镜像 DR。
- **跨角色动作参考**：只迁移骨架、夸张程度、握点或惯性方向。当前已批准赤柴 Hit 运行时图 `godot/assets/units/actions/doge_hunter_hit_dr.png` 是标准胶囊角色受击夸张程度的只读参考，不是其他犬种的身份母图。

## 动作预演：纯橙 Stick-Figure Gate

当动作的冻结时刻、力线、重心、接触关系、负形或夸张程度仍有分歧时，必须先于正式 ImageGen 绘制 `1–4` 张纯橙单色火柴人缩略预演。按 [`pose-proof.md`](pose-proof.md) 使用 `scripts/pose_proof.py render-options` 从轻量 Draft 确定性生成 Review 看板及 128 预览。草图使用最终方向、摄像机和大致画布占位，可以包含抽象装备轴，但不得携带犬种、服装、角色配色、装备造型、材质或技术检测框。由 `cty41` 选择姿态后运行 `select-option`，再建立精确 Composition。

Idle 微调、exact-chroma 等技术清理，以及同一目标 asset/pose/direction 已具有完整批准链的姿态复用可通过不可变 receipt 豁免；其他资产的 Approval 或裸图不能借用。确定性 Assembly 若目标尚未批准，仍需至少建立单方案 Action Card。未选草图和 review board 不是正式 Attempt/Series/state；Action Card 只记录所选姿态、主要否决理由和人工决定，完整未选几何及临时 PNG 不进入 Git。新 `action_pose` Composition schema v3 必须绑定该 Card 或有效豁免；历史 schema v2 记录不回写。

## Pose / Identity / Equipment / Geometry 四类职责

- **纯橙 Pose sketch**：只负责动作时点、力线、重心、接触、负形和剪影。
- **Identity anchor**：只负责物种、脸、核心体量、配色和画风。
- **Equipment anchor**：只负责精确形制、比例与装备状态。
- **Composition / Pose Guide**：姿态选定后才负责 baseline、握点、端点、遮挡层和安全区；多色技术 Guide 不能代替纯橙姿态预演。
- **ImageGen**：只综合已经批准的职责，不负责重新设计动作，也不拥有终审权。

## ImageGen 停止与换策略信号

每生成一张候选就停止并等待 `selected / retry / stop`。姿态尚未通过纯橙预演、来源职责冲突、运行时时点不匹配、连续两轮重复同一语义失败、模型持续重画冻结区域，或确定性 Assembly 已能完成时，立即停止 ImageGen 并回到对应决策层。默认 generation round `3` 是流程预算与停止信号；Reviewer 自动闭环硬限制在三轮以内。普通/equipment retry 的现行 CLI 尚未统一强制该上限，因此只有直接人工决定才应继续第 4 张及以后候选，不能把流程约束误写成已由所有命令实施的硬门禁。

最小人工门禁为：G0 确认 gameplay consumer、Visual Moment 和 Sprite/Tween/VFX 分工；G1 选择纯橙姿态；G2 确认来源职责；G3 逐张判定候选；G4 检查 256、128、状态集和 Game View；G5 分别批准 promotion 与 runtime 接入。

## 3D 姿势到等距投影

- 动作提示词按“世界空间角色朝向与局部动作 → 固定等距摄像机 → 屏幕空间验收”三层书写。只写“向左倾”“后仰”或“顺/逆时针”会把角色局部方向、摄像机方向和屏幕方向混在一起。
- 世界层至少声明角色面向、目标方向、身体沿自身前/后/侧方的位移，以及装备位于摄像机近侧还是远侧。摄像机层声明固定观察象限和背向/正向三分之四解剖。屏幕层必须声明主体顶部相对脚底中心的 `x` 关系、武器两端所在象限、杆身是否被身体遮挡，以及每只手的绘制顺序。
- 屏幕坐标是最终验收，不是可选描述。比如“顶部 `x <` 脚底中心 `x`”才代表画面左倾；不得根据身体一侧的弧线、耳朵或武器包围盒推断倾斜方向。
- DR 动作参考只锁定冻结时刻和装备状态。UL 必须从正式 UL 母图原生重绘，并把屏幕空间端点与层级逐项写出；不得假定镜像或“相反方向”会自动得到正确的 3D 关系。

## 裂颚羊魔长柄动作契约

- 正式身份母图仍是 `splitjaw_goat_charger_color_v05.png`（DR）与 `splitjaw_goat_charger_color_ul_v01.png`（UL）。母图中红棕杆连接的深色分叉轮廓是唯一武器刃头，不是第二把武器或独立尾巴；动作图不额外绘制可见尾巴。
- 当前人工确认的 UL 主体投影要求顶部中心位于脚底中心左侧，但武器轴按动作区分。Melee UL 已批准为斧刃左上、杆尾右下；Thrown UL 必须从 DR 的过顶姿势在 3D 中转向背面后再投影，保留“斧刃在上、杆尾在下”，同时把水平斜向翻转为斧刃右上、杆尾左下。
- UL 的双手与整把长柄武器绘制在胶囊身体后层：先画武器和手，再画身体遮挡杆身中段和手掌内侧。两个手掌只能露出贴着胶囊边缘的外弧，仍须与主体形成多像素 alpha 接触；不能浮空、用细线或长臂连接。
- 已批准 DR Thrown 采用斧刃左上、杆尾右下且整斧/双手前层的屏幕契约。生成 UL 时继承投掷冻结时刻、紧凑武器长度和斧刃高于杆尾的 3D 关系；背向投影后水平斜向改为斧刃右上、杆尾左下，绘制顺序改为整斧/双手后层。

## Cast 施法轴

- 施法读图由“主体向目标前倾 + 主装备同向前指 + 空手辅助引导”共同构成，不能只抬手而让法杖保持 Idle 竖直。
- 法杖类装备把晶体/杖头作为施法轴最前端。持杖手中心默认位于杆尾至晶体底座之间的直杆中点，手掌两侧露杆比例验收范围为 `45:55–55:45`。计算时不包含晶体，不接受杆尾四分之一或三分之一握持。
- 杆身必须位于眼睛和口鼻下方，不遮脸、不穿过主体，不为追求指向性而拉长成长杆。短匕首、盾牌等非杆状装备只迁移方向语义，不套用中点握持比例。

## Hit 统一漫画语言

- 标准地面胶囊角色的默认 Hit 峰值采用与已批准赤柴一致的中度 Q 版漫画夸张：核心主体作为刚体整体向来击反侧后仰，耳朵后折/压低，可见眼睛放大眼白并缩小瞳孔，口部使用紧张的小波浪线。
- DR 两眼可见时，默认从双眼各画一条短而清晰的蓝白泪线。泪线是面部反应符号，只允许两条；不生成水花群、额外水滴、星星、命中闪光、伤口、数字或魔法泄漏。
- UL 保留同一冻结时刻的主体倾斜、耳朵惯性、装备偏转和泪线运动方向，但只画背向三分之四解剖上真实可见的眼睛和泪线。不把 UL 重画为带完整正脸的假背面。
- 角色装备状态始终由该角色的动作提示词库决定。法师 Hit 保留唯一晶体法杖；死灵 Hit 保留唯一匕首并完全移除 Idle 蓝色鬼火；不从赤柴参考迁移无矛或圆盾状态。

## DR / UL 逐图门禁

高风险动作在 ImageGen 前必须落成 schema v2 `compositionSpec`：用屏幕坐标固定核心轴及倾角、脚底中心、隐藏握点、武器轮廓出口、剑尖目标区、眼睛禁入区、宝石面积和剑鞘状态。由状态机确定性渲染的 pose guide 只约束构图，不承担身份或画风。调用前编译的 prompt 必须同时重复正式母图不变量、参考职责、冻结项和未解决修正项。

1. 每次只生成一个角色、一个动作和一个方向的一张候选；展示 `256×256` 结果后停止，不因技术通过自动批准或进入下一张。
2. DR 需人工确认动作语义和角色身份后，才能用于 UL 的动作参考。“继续 UL / top-left”可作为继续生成授权，但不等于候选已晋升到 `calibrated`。
3. UL 同时输入正式 UL 身份母图和已选 DR 动作图；提示中逐张标明“身份母图”与“动作参考”的责任，禁止两者互换。
4. 核心蒙版、`_128` 和 Tile Review 仍遵守尺寸契约。未完成这些完整 Review 材料的图只能记为候选/逐图迭代，不得写成已批准发布图。
5. 视觉模型可指出犬种、目光、剑鞘、表情或武器风格风险，但 advisory 永远不是硬门禁，也不能代替用户确认。正式批准必须绑定候选、蒙版、annotations、验证报告与全部 Review 哈希。

## Checklist

- [ ] 正式方向母图、DR 动作图与跨角色参考的责任没有混用。
- [ ] Cast 装备轴指向目标；法杖握点在直杆中点容差内且不遮脸。
- [ ] Hit 与赤柴的漫画夸张程度一致，但角色身份、体量和装备没有被参考图替换。
- [ ] UL 是原生背向三分之四重绘，只显示解剖上可见的脸部与泪线。
- [ ] 提示词已同时声明 3D 动作、固定等距摄像机和可测量的 2D 屏幕验收点。
- [ ] 羊魔 UL 已检查顶部 `x <` 脚底中心 `x`、动作专属武器轴、武器与双手后层、无独立尾巴和无手臂。
- [ ] 逐图展示后已停止；候选未经完整 Review 时没有晋升或接入运行时。
